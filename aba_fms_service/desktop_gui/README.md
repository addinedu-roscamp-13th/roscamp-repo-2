# desktop_gui

이 폴더는 PyQt 기반의 데스크톱 GUI 프로젝트를 둡니다.

## 역할

- 중앙 관제용 로컬 GUI
- FMS 관련 운영 패널
- 로봇 상태 조회, 수동 제어, 알림 확인

## 구성 원칙

- 이 폴더는 PyQt 전용입니다.
- 웹 프론트엔드와는 분리합니다.
- 비즈니스 로직은 가능하면 `fms_service/backend` 와 API로 연결합니다.
- 로컬 실행 경로와 설정은 이 폴더 안에 별도로 둡니다.

## 메모

- 현재는 골격만 둔 상태입니다.
- 실제 PyQt 앱 구조가 정해지면 `src/`, `ui/`, `assets/`, `scripts/` 같은 하위 폴더를 추가하면 됩니다.
