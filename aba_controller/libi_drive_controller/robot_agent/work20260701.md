# 작업 기록 — 2026-07-01 (robot_agent 아르코 마커 도킹)

## 개요
로봇 온보드 에이전트(robot_agent)에 **아르코(ArUco) 마커 도킹 정렬** 기능을 추가했다.
로봇 카메라로 마커를 검출해 로봇을 마커 정면·일정 거리로 미세 조정(도킹)한다.
중앙 관제(bot_ai_server, 192.168.0.19:9002/admin/aruco)에서 이 엔드포인트를 직접 호출해 테스트한다.

## 추가/수정 파일
- `robot_agent/app/routers/aruco_dock.py` (신규)
  - 엔드포인트: `GET /dock/detect`, `POST /dock/start`, `POST /dock/stop`, `GET /dock/status`
  - server.py 에서 `/api/admin/robot` prefix 로 장착 → 실제 경로 `/api/admin/robot/dock/*`
  - **OpenCV 4.6(구 API) / 4.7+(신 API) 호환 shim** 포함 (이 로봇은 cv2 4.6.0)
  - 모터는 `driving._motor_send / _vel_to_speeds` 재사용(차동구동, MAX_SPEED=75), 인증 없음(에이전트 내부용)
  - 기본 픽셀 기반 제어(마커 중심 ex 로 회전 정렬 + 화면 내 마커 크기로 전진). `config/camera_calib.npz` + marker_len_m + target_distance_m 있으면 solvePnP 미터 제어
  - 안전장치: 마커 상실 시 정지→(옵션)재탐색, 타임아웃, 속도 상한, 종료 시 모터 0
- `robot_agent/app/core/server.py` — driving 분기에 aruco_dock 라우터 등록 (`server.py.bak` 백업)

## 구동 / 재시작
- systemd 서비스: `robot_agent.service` → `scripts/service_run.sh`(ROS2 jazzy 소싱 + venv) → `main.py`
- 재시작: `sudo systemctl restart robot_agent`
  - ⚠️ `./start.sh` 는 ROS 미소싱이라 rclpy import 실패 + 포트충돌 → 사용 금지

## 검증
- `GET http://192.168.0.28:9001/api/admin/robot/dock/detect` → 프레임 640x480, cv2 4.6.0, 마커 id=7 검출(ex/size_frac/skew 산출) 정상
- 카메라 스트림 `/api/admin/robot/camera/stream` (MJPEG) 정상, 인증 불필요
- 모터 구동(`/dock/start`) 실기 테스트는 사람 감독 하에 관제 페이지에서 진행
