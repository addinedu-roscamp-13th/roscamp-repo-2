# bbox 종횡비 가드 임계 실측

2026-07-31 · `~/Videos/libi_rec/` 두 편 · `segments_draft.md` 라벨 구간 기준 ·
`weights/best.pt` 검출 bbox · **프레임 경계에 닿은 bbox 는 제외**

## 결과

| | **pi (앞캠)** | **usb (뒷캠)** |
|---|---|---|
| standing 표본 (잘림 제외) | 112 | 200 |
| lying 표본 (잘림 제외) | 11 | 30 |
| standing h/w p5 / 중앙 / p95 | 2.86 / **3.25** / 3.70 | 2.05 / **2.95** / 4.67 |
| lying h/w p5 / 중앙 / p95 | 0.76 / **1.10** / 1.57 | 0.89 / **2.01** / 4.91 |

## 판정

### `BBOX_LYING_FRAC = 0.45` — **채택**

| | 임계 | lying 검출률 | standing 오탐 |
|---|---|---|---|
| pi | `3.25 × 0.45 = 1.46` | **91%** | **0.0%** |
| usb | `2.95 × 0.45 = 1.33` | 23% | 1.0% |

앞캠에서 깨끗하게 갈린다. 뒷캠은 검출률이 낮지만 **틀리는 방향이 안전한 쪽**이다
(누웠는데 못 잡음 → 키포인트 경로가 이어받음 / 서 있는데 누웠다고 하지는 않음).

뒷캠 lying 분포가 넓은 이유: 라벨 구간이 1초짜리 조각이고 그 안에 **회전 중 모션 블러와
대각선 자세**가 섞여 있다. 대각선으로 기운 피규어의 bbox 는 여전히 세로로 길다.

### `BBOX_SIDE_FRAC = 1.5` — **기본값 끔(`None`)**

| | 임계 | standing 중 걸리는 비율 |
|---|---|---|
| pi | `3.25 × 1.5 = 4.88` | **0.0%** — standing p95 가 3.70 이라 **한 번도 안 걸린다** |
| usb | `2.95 × 1.5 = 4.42` | **6.5%** — 전부 오탐이다 |

**작동하지 않는다.** 앞캠에서는 절대 안 걸리고 뒷캠에서는 오탐만 낸다.

**이유**: 이 피사체는 **팔·다리 자세가 bbox 폭을 지배한다.** 사람이면 어깨 폭이 지배해
yaw 에 크게 반응하지만, 피규어는 다리를 벌린 폭과 팔 위치가 폭을 정하므로 몸을 돌려도
bbox 폭이 별로 안 줄어든다. standing 구간 **안에서만도** 동적 범위가 1.29배(2.86→3.70)에
그친다 — 신호가 잡음에 묻힌다.

대조적으로 **키포인트 경로의 측면 신호는 동적 범위가 92배**다(어깨폭/몸통길이:
p5 0.059 · 중앙 0.480 · p95 0.626). 측면은 그쪽이 담당한다.

그래서 **`BBOX_SIDE_FRAC` 의 기본값을 `None`(꺼짐)으로 둔다.** 측정해서 작동하지 않는
임계를 기본값으로 내보내지 않는다. 파라미터 자체는 남긴다 — 피사체가 실제 사람으로
바뀌면 어깨 폭이 지배하게 되어 되살아날 신호이고, 캘리브가 분리도를 보고 켤 수 있다.

## 남는 위험 — codex 지적이 완전히 해소되지는 않았다

codex 는 "키포인트가 죽는 45% 프레임에서 `Side` 분기에 도달 못 한다" 고 지적했고,
bbox 로 `Side` 를 내는 것이 그 답이었다. 이 측정으로 **그 답의 절반이 무너졌다** —
누움은 bbox 로 덮이지만 **측면은 안 덮인다.**

남는 방어선:

1. 키포인트가 죽으면 `Unknown` → `PostureGate` 가 25프레임(≈1.7초) 뒤 정지.
2. 그 1.7초 동안은 LiDAR 전방 하드 스톱(`STOP_DIST = 0.25 m`)만이 받친다.
3. 벤치의 `fatal_misses` 가 이 구간을 **게이트 허용 프레임으로 세므로** 숫자로 드러난다.

**후속 후보** (이번 범위 밖):
`UNKNOWN_STOP_FRAMES` 를 상태별로 가르는 것 — 직전 판정이 `Side` 였다면 `Unknown` 유예를
25 가 아니라 5 정도로 줄인다. "방금 옆을 보고 있었고 지금 안 보인다" 는 "정면이었는데
잠깐 안 보인다" 와 다른 상황이다. 지금 넣지 않는 이유는 유예 시간이 정상 추종의 멈칫과
직결돼 실측 없이 건드리면 안 되기 때문이다(`constants.py:37-41` 이 이미 그 이력을 적고
있다 — 10 에서 25 로 올린 것이 현장 대응이었다).
